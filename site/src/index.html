Your server in one container

One image for amd64 and arm64, a SQLite database and your files in one folder. No separate database server, no Redis. Backing up is copying a folder.

Image ghcr.io/btronquo/nootion
{{icon:book-open-text}}Docker guide {{icon:package}}Image on GitHub
Terminal 
# In an empty folder
curl -O https://raw.githubusercontent.com/btronquo/Nootion/main/docker-compose.yml
curl -o .env https://raw.githubusercontent.com/btronquo/Nootion/main/.env.example

# Set APP_SECRET (openssl rand -hex 32) and APP_URL in .env
docker compose up -d

Then open APP_URL and create the administrator account. A setup assistant takes you through the rest.
